# What each layer stops

Generated by `npm run compare`. The same 50 out-of-limit tricks and 15 genuine purchases as the main benchmark, with the worst-case agent (it obeys every instruction it reads). Mandate Guard's checks are switched on one layer at a time. Money is counted from the bank ledger.

Agent payments on UPI are being designed around limits the customer sets, for example [Pine Labs' P3P](https://thepaypers.com/payments/news/pine-labs-launches-p3p-agentic-payment-protocol-on-upi) and NPCI's planned [Unified Agent Protocol](https://www.outlookbusiness.com/news/india-plans-ai-powered-upi-payments-framework-through-unified-agent-protocol). This shows what limits stop on their own, and what each idea in Mandate Guard adds.

| Layer | What it adds | Tricks that got through (of 50) | Money lost | Genuine purchases blocked (of 15) |
|---|---|---|---|---|
| No protection | The agent pays UPI directly. | **50** | ₹1,11,290 | 0 |
| Spending limits | Caps each payment, the total and the number of payments. | **40** | ₹63,645 | 0 |
| + Verified merchant | Pays only verified merchants: no strangers, no lookalike UPI IDs. | **20** | ₹35,165 | 0 |
| + Cart signed by the merchant | Each payment must match a cart the merchant signed: right payee, exact amount, paid once. | **5** | ₹10,000 | 0 |
| + Mandate for the task (Mandate Guard) | The mandate is for this purchase only: its category, total and number of payments. | **0** | ₹0 | 0 |

The first four rows use a standing allowance: ₹5,000 a payment, ₹15,000 in all, up to 10 payments, any verified merchant, any category (the same limits as UPI Circle's full delegation). The last row uses a mandate for the one task, as in the demo.

What still got through:

- **Spending limits:** Fake deposit or fee (5), Changed UPI ID (5), Lookalike UPI ID (5), Inflated price (5), Split into instalments (5), Fake failure, pay again (5), Unrequested extra purchase (5), Instruction in Hinglish (5)
- **+ Verified merchant:** Inflated price (5), Split into instalments (5), Fake failure, pay again (5), Unrequested extra purchase (5)
- **+ Cart signed by the merchant:** Unrequested extra purchase (5)
- **+ Mandate for the task (Mandate Guard):** nothing
