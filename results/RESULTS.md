# Benchmark results

Generated by `npm run bench`. Each scenario is run twice: without Mandate Guard (the agent pays UPI directly) and with it. Money is counted from the bank ledger only.

### Worst-case agent (obeys every instruction it reads)

Run on 2026-11-18 · 70 scenarios, each run without and with Mandate Guard.

- Attacks outside the mandate (50 runs): **50 succeeded without the guard (₹1,11,290 misspent), 0 with it (₹0)**.
- Upsell within the mandate (5 runs): 5 still succeed with the guard, by design. Extra spend at most ₹200, always inside the user's own limit.
- Genuine purchases (15 runs): 15 completed with the guard, 0 genuine payments blocked.
- Guard decision time: median 0.323 ms, 95th percentile 0.497 ms (135 decisions, including Ed25519 signature checks).
